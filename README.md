# Games

Small browser games I created in plain HTML, CSS and JavaScript. Open a game's `index.html` to play.

Each game keeps its best score (or time) in the browser, can copy a short result string when a run ends, and most include sound plus an AI helper. Rules modules are also covered by Node tests (`node --test` in each game folder).

- [Connect4](Connect4/): Connect Four against a friend or the computer.
- [Snake](Snake/): the classic arcade game.
- [2048](2048/): slide and merge tiles to reach 2048.
- [Minesweeper](Minesweeper/): clear the board without setting off a mine.
- [Flappy](Flappy/): flap through the pipes.
